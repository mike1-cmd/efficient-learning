# 各阶段可复用提示词

四个阶段各有一组可直接套用的提示词。用之前把 `{主题}`、`{目标}`、`{基础}` 替换成实际值。

---

## Step 1 · 双轨测（真实任务探底 + 出题补盲）

**1.1 先探底：给一个真实小任务，让我当场做**

```
我要学 {主题}，目标是 {目标}，目前基础是 {基础}。
先别教我任何内容，也别推荐资料。请给我 1 个该领域最典型的小任务，让我现在直接做：
- 10–20 分钟内能做完
- 不许我查资料
- 做完之后，你只观察三件事：我卡在哪一步、用了什么错方法、做出了什么
- 不要在我做之前给任何提示
```

**1.2 再补盲：只测任务照不出来的地方**

```
根据我刚才做任务的表现，出 8–12 道诊断题，只测两类地方：
① 任务里暴露的空白　② 任务做对了但看不出对错的判断点
四类各 25%：概念辨析 / 操作步骤 / 边界条件 / 常见错误
考边界和误用，不要考名词解释。不给提示，不夹带答案。
```

**1.3 判卷：只出三栏**

```
判卷。只输出三栏：已掌握 / 半懂（会用错，最危险）/ 空白，
最后用一句话说出我的缺口集中在哪里。不要开始讲课。
```

**判卷后的追打**（"半懂"那一栏必须处理）：

```
对标记为"半懂"的这 3 个点，各问我一个"什么情况下会失效"的问题，
我答完你再判断我是真懂还是会背。
```

---

## Step 2 · 提取 20% 骨架

```
关于 {主题}，请只给我撑起这个领域的骨架：
- 5–9 个核心概念（不超过 9 个）
- 2–3 条主关系，标明关系类型（属于 / 导致 / 依赖 / 对比）
每个概念给四件套：一句话定义、一个我能秒懂的类比、一个反例、一个最小可练动作。
另外单独列一段"这一阶段明确不学什么"。
表达方式：能画图的别写字，能列表的别写段落。
```

**要求补图形化**（当回复又变成大段文字时）：

```
把刚才这段改成一屏能看完的结构：并排的用两列表格，有先后用箭头，有层级用缩进。
不要新增内容，只换表达形式。
```

---

## Step 3 · 设计微项目

```
基于这 {N} 个核心概念，给我一条动手路径，每个概念一个动作：
- 单个动作 5–30 分钟内可完成
- 必须有可见产物（文件 / 截图 / 一段能跑的东西 / 讲给一个人听）
- 三级递进：抄（照样例复现）→ 改（改参数或场景）→ 造（脱离样例独立做）
- 每个动作先给验收标准："做对了长什么样"
按勾选清单格式输出，我要能直接打勾。
```

**卡住时**：

```
我卡在 {具体现象}。先别给答案，问我 3 个能自己定位问题的问题。
```

---

## Step 4 · 先自己画，再让 AI 查

**用户自己画之前，AI 只做这一件事**：给画图规范，不给内容。

```
我要自己画 {主题} 的知识图谱。只给我规范和检查表，不要给我任何节点内容。
规范：节点=概念，边=关系并标注类型（属于/导致/依赖/对比），一个节点只能有一个主父级。
```

**画完之后**才发这张（把图贴进来）：

```
这是我画的图谱（见下）。请当审稿人，不要重画。
按四类错误逐条查，每条给"错在哪 + 改成什么"：
1. 漏节点：核心概念是否缺失或被边缘化
2. 方向错：因果、依赖、包含关系是否反了
3. 层级错位：并列是否被写成父子，或反之
4. 循环与同义反复：是否存在互相定义、同义词自证
最后列出 3 个我这张图里仍然模糊的点。
```

**更强的一版（追问式，推荐）**：

```
看我的图谱，挑出你认为最可疑的 3 条边，每条只问我一个问题："这条边为什么是这个方向/这个类型？"
我答完你再判断对错，不要提前公布答案。
```

---

## 闭环回测

```
从我的图谱里出 5 道题：3 道针对"仍然模糊的点"，2 道针对两条主关系。
全是应用题，不要名词解释。答对 4 道以上算这轮闭环通过。
```

---

## 全流程一句话版（用户想一口气跑完时）

```
用高效学习六阶闭环带我学 {主题}，目标 {目标}，基础 {基础}。
严格按顺序：先测再学 → 只讲 20% 骨架 → 每学一个就让我动手 → 最后我自己画图谱你来查错。
每一步只推进一步，等我做完再走下一步。别一次给我全部内容。
```

---

## 第 3 阶收尾 · 费曼输出

```
现在做费曼输出：不许看笔记、不许看刚才的对话，用你自己的话把 {主题} 讲一遍。
- 讲给一个完全不懂这个领域的人听，不许用专业术语；非要用的，先解释它是什么。
- 录音或打字都行，先讲 3 分钟不中断。
- 讲完把你卡住的地方标出来——卡住的地方就是没懂的地方。
讲完我再听，不替你补。
```

---

## 闭环通过后 · 复习提醒

```
跑一次 stage.py review <会话目录>，告诉我今天有没有到期的复习。

有：按 due 队列的顺序来，一次只做一个概念的自由回忆，别顺带讲新内容。
    每个概念：先让我给信心 1-5，再让我答；答完你对照事先写好的要点判分，
    然后让我跑 stage.py grade 把结果记进去 —— 一定要带上我的原话：
    --evidence "从我答案里摘一句最能代表这次表现的原句"
    （没带 evidence 的评分在 stats 里会被算成"无凭证"，不算掌握的证据）
没有：告诉我下次是哪个概念、哪天、还有几天。
```

## 判分（每一道回测题都用这套流程）

**出题时同时写出评分标准，但不写答案：**

```
出这道题的同时，在题目下面写 3–5 个「必须命中的要点」作为评分标准。
标准只描述"答到什么算过"，不许提前泄露答案，也不许写"参考上面讲的"。
```

**判分时：**

```
判这道题。只依据两样东西：我刚才的原话 + 你写好的评分标准。

禁止：
- 用"如我们刚才所说""按上面讲的定义"当判据
- 因为我表达流畅就给分
- 只给总分不逐条对照

要求：
逐条标出命中 / 未命中 / 部分命中，每条给出依据（我的原话片段）。
最后给一个档：错 / 勉强 / 对 / 轻松。
如果我答案里出现"就是刚才那个意思"这类指代，直接追问"具体指什么，说出来"。
判完把最能代表这次表现的那句原话摘出来，作为 grade 的 --evidence。
```

**对比校准（每轮回测收尾一次）**：

```
把我这一轮填的信心度和实际结果对一下：哪几题是我高估了自己？差多少？
如果整体高估超过 15 个百分点，直接告诉我：我的"懂了"目前不可信，该降信心基线。
```

## 第 5 阶 · 回测答错后（退阶重做）

```
这题我答错了，错在「{概念}」。
先跑 stage.py retry <会话目录> --concept "{概念}"，把状态退回第 3 阶。
然后只讲这一个概念：我错在哪、正确的关系是什么、它在什么情况下会失效。
不要顺带讲别的概念，也不要替我重做动作——动作我自己做，产物我自己填。
```

---

## 第 5 阶 · 同一概念连错 2 轮（回第 0 阶）

```
这个概念我两轮都没答对。
别再来一遍了，先跑 stage.py reset <会话目录> --reason "..."。
然后带我重新定靶：是目标定太大、时间预算不够，还是切入点选错了？
只问这三个问题，别问别的；问完把新的定靶四行写进 00-plan.md。
```

---

## 每次出题前 · 按引擎给的参数出题

```
先跑 coach.py next <会话目录>，把它给的四个参数（概念 / 角度 / 难度 / 桶）当硬约束。

你只做两件事：
1. 出一道符合这个角度的题，难度对齐「{难度描述}」，不许降级成名词解释。
2. 写 3–5 条评分标准，写在题边上，不许先写答案。

出完把题面用 coach.py add 存进题库；库里已经有同角度的题就直接用那道。
```

## 答完立刻记分

```
跑 coach.py record <会话目录> --concept "{概念}" --grade {对/勉强/错/轻松} \
  --angle {角度} --level {难度} --seconds {用时} --confidence {答题前的把握} \
  --evidence "{他的原句片段}"

evidence 必须是他真的说过的话，不是你的转述。没有原话这条就只是你的印象。
--seconds 要真填：答对但用时超过这个概念中位数 2.5 倍，脚本会自动按「勉强」计。
不要为了让成绩好看而不填用时——那等于把流畅度这条证据扔掉。
```

## 跨主题复盘（换主题前、或每周一次）

```
跑 coach.py profile <学习根目录>，把结果翻译成三句话：
1. 你在哪种问法下最容易错（只念最差的那个角度，附带正确率）
2. 你卡在哪一级难度（只念正确率最低的那级）
3. 你高估自己多少（校准偏差为正就说"你的懂了要打折扣"）

不要念全表，不要附带建议清单。三句话说完就停。
```

---

## 难度顶格时 · 不要硬考

```
next 已经说了「到最浅一档仍低于目标带」，这说明他对这个概念印象接近零。
不要继续出题。先用两分钟讲一个最小例子，讲完再 next 一次；难度还是 1 就说明前置概念缺了。
```

---

## 每五题一次 · 给难度模型对账

```
跑 coach.py calibration <会话目录>。

- 样本不足 5 条：直接说「现在还测不了，再答几题」，不许说「应该没问题」。
- 目标带实际通过率 < 55%：说「我一直高估你，难度整体降一档」，然后下一题降一档出。
- 目标带实际通过率 > 92%：说「太简单了，抬难度」，然后升一档。
- 在 55–92% 之间：一句「目标带站得住」就停，别念全表。

这是唯一能检验「预计 78%」是不是真的 78% 的地方。跳过它，那个数字就是编的。
```

---

## 每次开新回合 · 先问今天做什么

```
跑 coach.py today <会话目录>，把它给的「现在做这一件」原样执行。
不要自己重排优先级，也不要一次给出三个选项 —— 它已经按
「到期召回 > 补弱 > 练熟 > 新概念」排好了。
退出码 0 就直说今天没有到期项，可以休息或加练。
```

---

## 无提示召回 · 出题（最关键的一条）

```
跑 coach.py recall <会话目录> --json，按返回的 prompts 让用户讲，
但**只念概念名和四步的标题，不念具体问题、不念评分标准**。

- 限时按返回的 limit_sec，到点就停，不许「再想想」。
- 用户讲的时候不要插话、不要提示、不要说「对，就是那个」。
- 讲完再对照 rubric 逐条判：全中=对，中一半=勉强，想不起来=错。
- 判的时候引他的原话（evidence），不要写「理解得不错」这种印象式评语。
```

---

## 召回答错 · 不要重讲，先退阶

```
这个概念他刚才没想起来。先跑 stage.py retry <会话> --concept "X" 退回第 3 阶。
然后只讲一件事：他漏掉的是哪一步（是什么 / 何时失效 / 例子 / 关系），
为什么那一步会漏。不要从头讲一遍 —— 从头讲一遍是最省事也最没用的做法。
```

---

## 判「已掌握」之前 · 先看两个日子

```
跑 coach.py report <会话目录>，看目标概念那一行：
- 状态写「当场会（未跨天验证）」→ 不许说「你掌握了」，只能说「这一轮会了」。
- 状态写「已掌握」→ 可以说，但要附带稳定度和下次召回日期。
- 「还差：跨天提取 1/2 天」→ 直接把这个缺口念给他，并说明下次什么时候来验证。
```

---

## 校准之后 · 把偏差写回去

```
calibration 报了偏移，就跑到 --apply。只喊「下次注意」等于没校准。
写回后告诉用户两件事：偏移是多少、从下一题起会怎么变（更难/更易、间隔更长/更短）。
样本不到 20 条时它拒绝写入 —— 这时如实说「样本不够，先不改」。
```
