# 方法论：为什么是这个顺序

## 一、先测再学（Test-first）

**机制**：先答错，再学，记忆留存显著高于先学后测（pretesting effect）。原因有三：错误答案制造"认知缺口"，让后续输入变成补洞而非铺墙；测出来的信息直接用于定靶；避免把时间花在已经会的内容上。

**双轨设计（真实任务 + 出题）**：单靠出题有个盲区——题是出题人认为重要的地方，不是用户实际会栽的地方。所以先用一个**真实小任务**探底，暴露"动手时才崩"的问题，再用题目去测任务照不出来的判断点。顺序不能反：先题目后任务，用户已经被题目提示过一遍，任务的探底价值就没了。

**操作要点**：
- 任务要**小而完整**：10–20 分钟能做完，且能看出对错。不要"请你设计一个系统"这种无从判卷的题。
- 任务期间**禁止查资料**，查资料就把测试变成了阅读。
- 题目要考**边界和误用**，不要考名词解释。好题的样子："这个参数在什么情况下会失效？"
- 判卷必须落在"半懂"这一档上。半懂的人最危险：他不会再主动学，但会持续用错。

**自测变体**（无人出题时）：
1. 合上书，用 3 分钟写下关于这个主题你知道的一切（brain dump）。
2. 标出其中没把握的部分。
3. 用一个小任务验证：能不能做出最小可用版本。

## 二、优先学核心（20% 骨架）

**机制**：领域知识是长尾分布。少数概念构成骨架，其余概念要么是骨架的推论，要么是边缘细节。先有骨架，新知识才有挂载点；没有骨架的输入会变成一堆互不相连的碎片，也就是"看了很多教程还是不会"的真正原因。

**判定骨架的方法**：
- 问"删掉这个概念，这个领域还成立吗？"——不成立的是骨架。
- 问"这个概念在后文被引用了几次？"——高频引用的是骨架。
- 问"外行最常在此处误解什么？"——误解集中的地方是骨架。

**表达要求**：文字是线性的，结构是网状的。把网状结构用线性文字描述，必然丢失关系。所以必须图形化：
- 并列 → 表格的双列
- 流程 → 箭头
- 层级 → 缩进
- 因果 → 因为/所以显式连线
- 抽象 → 类比（找一个用户已知的同构物）

## 三、学完就动手（输出驱动）

**机制**：生成效应（generation effect）——自己产出的内容比读到的内容记得牢；同时，动手会立刻暴露"以为懂了其实没懂"的地方，形成纠错回路。

**微动作设计原则**：
- **短**：5–30 分钟能完成，否则启动成本高到不会启动。
- **有产物**：产物能被看见、被运行、被他人读到。没有产物的练习等于没练。
- **有验收**："做对了长什么样"必须提前写清楚，否则做完不知道对错。
- **三级递进**：抄 → 改 → 造。跳过"抄"会让新手卡在环境与细节上；停在"抄"则永远独立不了。

**成就感为什么写进方法里**：学习是长周期低反馈行为。每完成一个微动作就打勾、就产出一个可见文件，等于人为制造反馈密度。没有这一步，方法再对也坚持不过三天。

## 四、自己整理结构 + AI 查错

**机制**：把知识重组成结构，是最高强度的加工（organizational processing）。这一步一旦外包给 AI，加工就消失了，用户得到的是一张"看起来懂了"的图。

**分工必须严格**：
- 学习者：画图、标关系、写关系类型。
- AI：查四类错误、追问为什么这么连、出下一轮题。

**AI 检查清单**（四类错误）：
1. 漏节点：核心概念缺失，或只挂在一个边角上。
2. 方向错：因果反了、依赖反了、包含关系写成并列。
3. 层级错位：把并列写成父子，或把父子写成并列。
4. 循环与同义反复：A 靠 B 定义，B 又靠 A 定义；或用同义词解释自己。

**追问式检查优于批改式检查**：先问"这条边为什么是这个方向？"，让用户自己发现错误，比直接标红有效得多。

## 五、判分必须和讲课分开

**机制：流畅性错觉（fluency illusion）。** 刚听完讲解时，材料的"处理流畅度"极高，人会把这个流畅感误当成"我掌握了"。这时候让他自评，几乎必然高估。更糟的是，讲课的人（包括 AI）也被同样的流畅感影响：他刚把一个概念讲得很漂亮，再看用户的答案，会不自觉地按"听起来像不像我讲的"来打分，而不是按"答案对不对"。

**所以要分权**：

- **讲课的一方不判分**，或者至少不复述自己的讲解当判据。
- **判分只看两样东西**：用户的原话 + 事先写好的评分标准。标准在出题时就固定，不能事后调整。
- **信心先于答案**：让用户在看到结果前给出 1–5 的把握度。这是唯一能捕捉"高估自己"的原始数据。

**为什么这条值钱**：判低了的代价是重做一遍已掌握的内容，浪费几分钟；判高了的代价是他以为自己会了，**于是停止复习**——而停止复习是不可逆的，等到发现时已经忘光了。两个方向的代价不对称，所以宁可严一点。

**可验证的形式**：把信心和结果都记下来，算校准偏差（预测通过率 − 实际通过率）和 Brier 分数。持续为正的偏差就是"你的懂了不可信"的量化证据。这比任何"你要谦虚一点"的说教都有效。

## 六、复习不是均匀排的

**机制：遗忘曲线是每个概念一条，不是全局一条。**

固定间隔（D+1 / D+3 / D+7 / D+14）的问题不在"间隔"这个想法，而在"统一"。同一个主题里的概念，难度能差一个数量级：有的听一遍就记住，有的一周后连名字都想不起来。给它们同一个节奏会同时造成两种浪费：

- 难概念：每次复习都落在它已经快忘光的时候，等于每次都在重学，稳定度永远涨不上去。
- 易概念：明明记得住，却被反复拉回来复习，挤掉了本来能学新东西的时间。

**FSRS 的做法**（Free Spaced Repetition Scheduler，Anki 现代版本默认用同族算法）：

| 概念 | 含义 | 怎么变 |
| --- | --- | --- |
| **S 稳定度** | 记忆能撑多久（天） | 答对拉长，答错骤降，且衰减幅度与当时的可回忆概率相关 |
| **D 难度** | 这个概念对这个学习者有多难（1–10） | 答错升高，答对向均值缓慢回归 |
| **R 可回忆概率** | 此刻还能想起来的概率 | R = (1 + 0.2346 × t / S)^(−0.5) |

下一次间隔由 `S` 和目标留存率反解出来，不是查表。效果：答对同一个概念三次，间隔大致是 4 天 → 14 天 → 47 天；答错一次，直接退回 1–2 天。这个增长曲线在 Anki 的真实数据上验证过。

**实证支撑**：三次**间隔**开来的复习各答对一次，一周后的回忆率约 68%；同样三次**连续**填鸭式复习，一周后约 26%。差别不在复习次数，全在间隔上。所以"学完排复习"不是附加服务，是学习本身的一部分。

**为什么用代码算而不是让模型估**：日期计算是可验证的确定性任务。模型心算日期会错，而且同一份数据算两次结果可能不一样 —— 一个会漂移的调度器等于没有调度器。

**指标要诚实**：

- 留存率必须带样本量和时间窗。"100%" 可能只是 1 题对 1 题。
- 到期但没复习的概念算**未知**（unmeasured），不算"忘了"。但 unmeasured 长期很高，说明闭环其实没闭上。
- 首次就答错不记作 lapse —— lapse 的语义是"记住过又忘了"，混淆两者会让难度估计失真。

## 为什么要有硬门禁

六阶里最容易被砍掉的是第 1 阶（测）和第 4 阶（图谱）：Step 1 砍掉还能立刻看到内容，感觉"效率高"；Step 4 砍掉是因为自己画图比看别人画的图累。这两步恰恰是留存率的主要来源。所以把"不许跳"写成明规则，而不是靠自觉：

- G1 未测不讲：保证讲的内容是用户缺的，不是讲的人顺手的。
- G2 未做不进：保证每个概念都过了手，而不是过了眼。
- G3 未画不查：保证结构化加工发生在学习者脑子里，而不是发生在对话框里。

门禁的作用是**替用户挡住他自己的偷懒冲动**，不是刁难用户。所以降级阀只留一个，且降级后要留痕（产出首行标注"本轮不计入闭环通过"）。

## 常见误区

| 误区 | 症状 | 纠正 |
|------|------|------|
| 收集癖 | 存了 50 个教程没看完一个 | 只允许同时存在 1 个输入源 |
| 大纲幻觉 | 计划漂亮，一步没做 | 计划里每一步都必须有产物 |
| 假装学习 | 看视频点头，合上就空 | 每 20 分钟强制输出一句自己的话 |
| 完美主义 | 反复重学第一章 | 先跑通最小闭环，再回补细节 |
| AI 代劳 | 让 AI 总结、让 AI 画图 | AI 只出题、只查错 |
| 无回测 | 学完不测，以为会了 | 图谱出题，答对才算过 |
| 无限补漏 | 同一概念反复错，一直重学同一段 | 连错 2 轮判定为「目标或方法错了」，强制回第 0 阶重定靶 |
| 数连击判掌握 | 连对 30 题才算会，90% 正确率的人一次通过率仅 4.2%，掌握变成炼狱（mathua 文档记录的真实故障） | 按角度覆盖 + 难度上限 + 稳定度 + 近期正确率四类证据判，连对数不进公式 |
| 同角度刷题 | 换个题面还是同一个问法，以为做了很多题 | 六个角度轮换；同一角度连问三遍记为一份证据 |
| 难度恒定 | 一直问同一档，要么无聊要么挫败 | 按掌握度反解难度，让预计做对率落在 70–85% |
| 练习全喂曲线 | 一天练五遍，间隔被虚抬成三周 | 同一天第二条起只算练习，不动 S/D |
| 只看对错不看速度 | 想半天答对也算会，真实场景里就是超时 | 慢过本概念中位数 2.5 倍按「勉强」计，不判错也不给满分 |
| 预测从不核对 | 每道题报个「预计 78%」，谁也不知道准不准 | `calibration` 出 Brier 分数与分档表，目标带实际不到五成就是模型错了 |
| 记忆只当报表 | 跨主题档案只在复盘时看一眼，不影响出题 | 历史正确率 <50% 的角度，在新概念里优先问 |
| 当天判掌握 | 一天答对四道题就宣布「学会了」，第二天归零 | 分两档：当场会（角度+难度+正确率）→ 已掌握（再加 ≥2 个不同日子成功提取 + S≥7） |
| 用重读代替回忆 | 复习就是把笔记再看一遍，看着都眼熟 | 无提示自由回忆：只给概念名，限时讲四步；眼熟不等于想得起 |
| 召回时给足线索 | 题干里已经含了一半答案，答对算通过 | 题干本身就是提示；回忆阶段只给概念名，评分标准答完才给 |
| 攒复习 | 忙了三天，到期堆到 20 个，一次做不完就彻底不做 | 到期就做第一个；做 1 个也比做 0 个好，间隔会按实际表现重排 |
| 覆盖式回测 | 重测时把上一轮的错题行改掉，看不出连错 | 回测表只追加不覆盖，按轮次列累计 |
| 自评幻觉 | 自己出题自己判，答得流畅就算过 | 判分只看原话 + 事先写好的标准；先记信心再看结果 |
| 平均主义复习 | 所有概念同一个节奏 | 每个概念一条曲线，间隔由 S/D 算出 |
| 收据缺失 | 回测题不绑概念名，答对也排不进复习 | 每题必须落到一个具体概念，否则等于白测 |
| 无产物打卡 | 打了勾但产物列空着，或路径根本不存在 | 产物是被验的对象，不是被声明的对象 |

## 为什么「当场会」不等于「已掌握」

记忆不是存进去就固定了。白天学会的东西先落在快而不稳的痕迹里，要经过睡眠才逐步固化
（consolidation）。同一天里反复答对，测的是这份还不稳的痕迹 —— 它能撑过一小时，
不代表能撑过一周。

两个直接推论：

1. **同一天的证据只有一天的分量。** 一天答对十次和答对一次，在「能不能记住」这个问题上
   提供的信息几乎一样多。所以判掌握看的是「有几个不同的日子成功提取过」，不是「答对几次」。
2. **提取本身才是加固动作。** 重读会让材料变眼熟（fluency 错觉），提取（retrieval）
   才会重写记忆痕迹。所以召回必须是「什么都不给，自己讲」，不是「再看一遍笔记」。

## 为什么召回不能给提示

「认得出」和「想得起」走的是两条不同的路。给一个题干、给四个选项、给一个首字，
用户走的是再认（recognition）；真实场景里没有这些线索，要用的是自由回忆（free recall）。

只练再认的人，考试换个问法就不会，工作里换个场景就断。所以 `recall` 只给概念名，
四步骨架是「该讲到的四个方面」，不是四个提示。

## 不同场景的调参

| 场景 | 调整 |
|------|------|
| 学工具/软件（如 Excel、Figma） | 压缩 Step 2，加重 Step 3；核心概念换成"5 个高频操作 + 3 个必踩坑" |
| 学理论/学科（如统计、经济学） | 加重 Step 1 和 Step 4；Step 3 的产物改为"用自己的话讲一遍 + 举一个反例" |
| 备考 | Step 1 直接用真题当诊断；Step 3 的产物是错题本；Step 4 图谱按考纲层级组织；考前把 `request_retention` 调到 0.95，召回密度加倍 |
| 面试/答辩 | 召回一律用「讲给别人听」，限时压到 60 秒；答不出来按错处理，不许「我其实知道」 |
| 行业/商业知识 | Step 1 的探底任务换成"对一家公司/一个模式下判断"；Step 3 产物是"带理由的判断"，不是笔记 |
| 转行/长期 | 拆成多个 2 周闭环，每个闭环一个可交付成果，闭环之间不重叠 |
| 带新人 | 先把 Step 1 交给新人自测，你只看三栏结果，再决定讲什么 |

## 来源

这套顺序不是独创，是几个成熟结论的组合：先测效应（pretesting）、生成效应（generation）、双重编码（dual coding）、提取练习（retrieval practice）、间隔重复（spaced repetition）、刻意练习的即时反馈原则、元认知校准（metacognitive calibration），以及帕累托式的最小可行知识。

**具体来源：**

- 间隔与遗忘曲线：Ebbinghaus（1885）；Cepeda et al.（2006）对 254 项研究的元分析；Karpicke & Roediger（2008）关于提取练习的经典实验。
- FSRS 算法：open-spaced-repetition 社区的 FSRS-4.5（Anki 现代版本的默认调度族），参数公开、可复现。
- 流畅性错觉与校准：Bjork 的"合意困难"（desirable difficulties）系列工作；Koriat & Bjork（2005）关于元认知判断失准的研究。
- 分权评审（工作产出者不给自己打分）：这一条在软件工程与研究工作流里都是共识，本技能借用的是同一原则。同源实践可参考 [nagisanzenin/engram](https://github.com/nagisanzenin/engram)（导师/考官/调度器三方分离）与 [open-spaced-repetition/fsrs4anki](https://github.com/open-spaced-repetition/fsrs4anki)。

六阶的价值不在单点，而在**顺序**：先定位 → 再搭骨架 → 再验证 → 再结构化 → 再回测 → 再交给记忆曲线。
